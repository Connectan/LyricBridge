**Spotify で再生中の曲に合わせて、リアルタイムに同期した歌詞を「通知」「Island／ステータスバー」「ロック画面」に流す Android アプリです。**

再生中の曲名・アーティスト・再生位置を Spotify のメディアセッションから読み取ります。歌詞は [LRCLIB](https://lrclib.net) から自動で探して、今歌っている行を表示し続けます。
LRCLIB に無い曲や端末内の曲には、自分で用意した `.lrc` ファイルを割り当てることもできます。

---

## ⚠️ 最初に読んでね

- 配布している APK は **v1.0（正式版）** です。パッケージ名は `com.connectan.lyricbridge` で、デバッグビルドではないリリース版です。
- 対応しているのは **Spotify（`com.spotify.music`）だけ** です。ほかの音楽アプリの曲には歌詞は出ません。
- 歌詞を探すのにインターネット（LRCLIB）を使います。
- Google Play 以外からの配布です。使用は自己責任でお願いします。

## できること

| 機能 | 内容 |
|---|---|
| 同期歌詞を自動で表示 | Spotify で曲を再生すると、LRCLIB から歌詞を探して、再生位置にぴったり合わせて 1 行ずつ表示します。間奏・イントロは「♪」で表示します |
| 通知に歌詞を表示 | 歌詞入りのメディア通知を出します。前の曲・再生／一時停止・次の曲の操作もそのまま Spotify に送れます |
| Island／ステータスバー歌詞 | アプリ専用のメディアセッションの「曲名」欄に今の歌詞を流すので、Island（画面上部のポップアップ表示）に対応した端末では歌詞が出ます。通知のティッカー文字列を使った「ステータスバー歌詞（実験）」もあります |
| ロック画面で全画面歌詞 | 画面オフ中やロック中に再生が始まると、ジャケット画像付きの全画面歌詞を自動で表示します。ロックを解除すると自動で閉じます |
| タイミング補正 | 歌詞がずれていると感じたら、±100ms 単位で微調整できます |
| 自分の LRC を使う | 端末内の `.lrc`／`.txt` を取り込んで、曲ごとに割り当てられます（UTF-8／Shift_JIS／GBK 対応）。LRCLIB に無い曲やローカルの曲向けです |
| 歌詞プレビュー | アプリの画面で、再生中の曲と歌詞の流れをそのまま確認できます |
| 診断ログ | ロック画面の起動や再生操作の履歴、前回のクラッシュ内容を見たりコピーしたりできます。うまく動かないときの原因探しに使えます |

## 使い方

1. アプリを開いて、画面に出る **必要な権限を許可** します（未設定の項目をタップすると、許可画面が開きます）
2. Spotify で曲を再生します
3. 歌詞が見つかると、通知・Island・アプリの画面に歌詞が流れ始めます
4. ロック画面に自動表示したい場合は、設定の「ロック画面で自動表示」をオンにします
5. 歌詞がずれていたら「歌詞タイミング補正」で調整します

## 必要な権限

| 権限 | 何に使うか |
|---|---|
| 通知へのアクセス | Spotify の再生状態とジャケット画像を取得するために **必須** です |
| 通知の表示（`POST_NOTIFICATIONS`） | 歌詞入りのメディア通知・Island 表示のため |
| 全画面通知（`USE_FULL_SCREEN_INTENT`） | ロック画面に歌詞画面を自動表示するため（Android 14 以降は許可が必要） |
| 他のアプリの上に重ねて表示（`SYSTEM_ALERT_WINDOW`） | 画面ロック中に歌詞画面を直接起動するため |
| 電池の最適化の除外 | 待機中にアプリが終了されないようにするため |
| フォアグラウンドサービス（メディア再生） | 歌詞の同期をバックグラウンドで続けるため |
| インターネット（`INTERNET`） | LRCLIB から歌詞を探すため |

> **Android 13 以降で「通知へのアクセス」をオンにできないとき**
> Google Play 以外から入れたアプリは、この権限が「制限付き設定」としてブロックされることがあります。
> 「設定」→「アプリ」→「LyricBridge」→ 右上の「︙」→「**制限付き設定を許可**」を押してから、もう一度オンにしてください。

> メーカー独自 ROM（MIUI／HyperOS、ColorOS など）では、「バックグラウンドでのポップアップ表示」や「自動起動」も許可しないと、ロック画面に自動表示されないことがあります。アプリ情報の画面から許可してください。

## インストール方法

1. [Releases](https://github.com/Connectan/LyricBridge/releases/latest) から APK をダウンロード
2. ダウンロードした APK をタップ
3. 「提供元不明のアプリ」の許可を求められたら、ブラウザ（またはファイルアプリ）に **このソースからのアプリを許可** をオンにする
4. 「インストール」を押す

> Google Play 以外からのインストールになるので、Play プロテクトの警告が出ることがあります。その場合は「詳細」→「インストールする」で進めてください。

## よくある質問

**Q. 歌詞が出てこない**
A. LRCLIB に登録されていない曲は歌詞が見つかりません。その場合は `.lrc` ファイルを用意して「この曲に LRC を割り当てる」から割り当ててください。インストゥルメンタルの曲は「インストゥルメンタル楽曲です」と表示されます。

**Q. 歌詞が少しずれる**
A. 「歌詞タイミング補正」で ±100ms 単位で調整できます。

**Q. 時間の情報が無い歌詞しか無い**
A. 同期できない歌詞は「同期なし（通常歌詞）」として全文を表示します。

**Q. Spotify 以外のアプリでも使える？**
A. 使えません。Spotify 専用です。

**Q. ロック画面に自動で出てこない**
A. 全画面通知・他のアプリの上に重ねて表示・電池の最適化の除外が許可されているか、アプリの「ロック画面表示の準備状況」で確認してください。メーカー独自 ROM では追加の許可が必要なことがあります（上の「必要な権限」を見てね）。
