**Spotify에서 재생 중인 곡에 맞춰, 실시간으로 동기화된 가사를 "알림", "아일랜드(Island)/상태 표시줄", "잠금 화면"에 띄워 주는 Android 앱입니다.**

Spotify의 미디어 세션에서 곡명, 아티스트, 재생 위치를 읽어 옵니다. 가사는 [LRCLIB](https://lrclib.net)에서 자동으로 찾아, 지금 부르고 있는 줄을 계속 보여 줍니다.
LRCLIB에 없는 곡이나 기기 안의 곡에는 직접 준비한 `.lrc` 파일을 지정할 수도 있습니다.

## ⚠️ 꼭 읽어 주세요

- 배포 중인 APK는 **v1.0(정식판)** 입니다. 패키지명은 `com.connectan.lyricbridge`이며, 디버그 빌드가 아닌 릴리스 빌드입니다.
- **Spotify(`com.spotify.music`)만 지원합니다**. 다른 음악 앱의 곡에는 가사가 나오지 않습니다.
- 가사를 찾을 때 인터넷(LRCLIB)을 사용합니다.
- Google Play 외부에서 배포하는 앱입니다. 사용은 본인 책임입니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 동기화 가사 자동 표시 | Spotify에서 곡을 재생하면 LRCLIB에서 가사를 찾아 재생 위치에 딱 맞춰 한 줄씩 보여 줍니다. 간주와 인트로는 "♪"로 표시합니다 |
| 알림에 가사 표시 | 가사가 들어간 미디어 알림을 띄웁니다. 이전 곡/재생·일시정지/다음 곡 조작도 그대로 Spotify에 전달됩니다 |
| 아일랜드/상태 표시줄 가사 | 앱 전용 미디어 세션의 "곡명" 칸에 현재 가사를 넣기 때문에, 아일랜드(화면 위쪽 팝업 표시)를 지원하는 기기에서는 가사가 표시됩니다. 알림의 티커 문자열을 이용한 "상태 표시줄 가사(실험)"도 있습니다 |
| 잠금 화면 전체 화면 가사 | 화면이 꺼져 있거나 잠겨 있을 때 재생이 시작되면, 앨범 아트가 들어간 전체 화면 가사를 자동으로 띄웁니다. 잠금을 해제하면 자동으로 닫힙니다 |
| 타이밍 보정 | 가사가 어긋난다고 느껴지면 ±100ms 단위로 미세 조정할 수 있습니다 |
| 내 LRC 사용 | 기기 안의 `.lrc`/`.txt` 파일을 가져와 곡마다 지정할 수 있습니다(UTF-8/Shift_JIS/GBK 지원). LRCLIB에 없는 곡이나 로컬 곡에 유용합니다 |
| 가사 미리보기 | 앱 화면에서 재생 중인 곡과 가사 흐름을 바로 확인할 수 있습니다 |
| 진단 로그 | 잠금 화면 실행과 재생 조작 기록, 지난번 크래시 내용을 보고 복사할 수 있습니다. 잘 안 될 때 원인을 찾는 데 쓰세요 |

## 사용 방법

1. 앱을 열고 화면에 나오는 **필요한 권한을 허용** 합니다(설정되지 않은 항목을 탭하면 허용 화면이 열립니다)
2. Spotify에서 곡을 재생합니다
3. 가사를 찾으면 알림, 아일랜드, 앱 화면에 가사가 흐르기 시작합니다
4. 잠금 화면에 자동으로 띄우고 싶다면 설정에서 "ロック画面で自動表示"(잠금 화면 자동 표시)를 켭니다
5. 가사가 어긋나면 "歌詞タイミング補正"(가사 타이밍 보정)으로 조정합니다

※ 앱 화면은 일본어입니다. 위의 설정 이름은 번역한 것입니다.

## 필요한 권한

| 권한 | 용도 |
|---|---|
| 알림 접근 | Spotify의 재생 상태와 앨범 아트를 가져오기 위해 **필수** |
| 알림 표시(`POST_NOTIFICATIONS`) | 가사가 들어간 미디어 알림과 아일랜드 표시를 위해 |
| 전체 화면 알림(`USE_FULL_SCREEN_INTENT`) | 잠금 화면에 가사 화면을 자동으로 띄우기 위해(Android 14 이상은 허용 필요) |
| 다른 앱 위에 표시(`SYSTEM_ALERT_WINDOW`) | 화면이 잠긴 상태에서 가사 화면을 바로 실행하기 위해 |
| 배터리 최적화 제외 | 대기 중에 앱이 종료되지 않도록 하기 위해 |
| 포그라운드 서비스(미디어 재생) | 백그라운드에서 가사 동기화를 계속하기 위해 |
| 인터넷(`INTERNET`) | LRCLIB에서 가사를 찾기 위해 |

> **Android 13 이상에서 "알림 접근"을 켤 수 없을 때**
> Google Play 외부에서 설치한 앱은 이 권한이 "제한된 설정"으로 차단될 수 있습니다.
> "설정" → "애플리케이션" → "LyricBridge" → 오른쪽 위 "⋮" → "**제한된 설정 허용**"을 누른 뒤 다시 켜 주세요.

> 제조사 커스텀 ROM(MIUI/HyperOS, ColorOS 등)에서는 "백그라운드에서 팝업 표시"와 "자동 실행"도 허용하지 않으면 잠금 화면에 자동으로 표시되지 않을 수 있습니다. 앱 정보 화면에서 허용해 주세요.

1. [Releases](https://github.com/Connectan/LyricBridge/releases/latest)에서 APK 다운로드

## 자주 묻는 질문

**Q. 가사가 나오지 않아요**
A. LRCLIB에 등록되지 않은 곡은 가사를 찾을 수 없습니다. 그럴 때는 `.lrc` 파일을 준비해 "この曲にLRCを割り当てる"(이 곡에 LRC 지정)로 지정해 주세요. 연주곡은 "インストゥルメンタル楽曲です"(연주곡입니다)라고 표시됩니다.

**Q. 가사가 조금 어긋나요**
A. 가사 타이밍 보정으로 ±100ms 단위로 조정할 수 있습니다.

**Q. 시간 정보가 없는 가사밖에 없어요**
A. 동기화할 수 없는 가사는 "同期なし (通常歌詞)"(동기화 없음, 일반 가사)로 전체를 표시합니다.

**Q. Spotify 말고 다른 앱에서도 쓸 수 있나요?**
A. 쓸 수 없습니다. Spotify 전용입니다.

**Q. 잠금 화면에 자동으로 나오지 않아요**
A. 앱의 "잠금 화면 표시 준비 상황"에서 전체 화면 알림, 다른 앱 위에 표시, 배터리 최적화 제외가 허용되어 있는지 확인해 주세요. 제조사 커스텀 ROM에서는 추가 허용이 필요할 수 있습니다(위의 "필요한 권한"을 참고하세요).
